# Changelog

## 0.2.0

- Difficulty math: hit chance, expected attempts, time to proof, near misses.
- `npm run example`: mine and verify one proof on the CPU.
- `npm run bench`: CPU hashrate of the TypeScript SHA-256.
- Protocol notes in `docs/protocol.md`.

## 0.1.0

- SHA-256 in TypeScript, attempt layout and the padded block for the shader.
- WebGPU search with a WGSL compute shader; CPU search and proof verification.
- Holder boost, upgrade tiers, GPU duty cycle, the signed round message.
